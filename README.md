# 다이아그래머

mermaid 코드를 넣으면 다이어그램이 되고, 그 다이어그램을 draw.io 처럼 마우스로 직접 편집하고,
파일로 내보내고, Obsidian 에 저장하는 로컬 프로그램입니다.

---

## 실행

Finder 에서 **`다이아그래머 실행.command`** 를 더블클릭하면 됩니다.
처음 한 번만 1~2분 걸리고, 그 다음부터는 몇 초 만에 브라우저가 열립니다.

터미널로 실행하려면:

```bash
npm install && npm run dev
```

`npm run dev` 는 파일 서버(5274)와 화면(5273)을 함께 띄웁니다. 브라우저에서 <http://localhost:5273> 을 엽니다.

> Node.js 가 없으면 <https://nodejs.org> 에서 LTS 버전을 먼저 설치하세요.

---

## 어떻게 만들어졌나 — 핵심 구조

mermaid 를 **화면에 그리는 도구로 쓰지 않습니다.** 파서와 배치 계산기로만 씁니다.

```
mermaid 코드
   │
   ├─ mermaid.mermaidAPI.getDiagramFromText() ─→ 구조 (노드 id·라벨·도형·스타일·연결)
   └─ mermaid.render() ─────────────────────── ─→ 배치 (좌표·크기·연결선 경로)
                                                      │
                                                      ▼
                                              Scene (자체 문서 모델)
                                                      │
                                       ┌──────────────┼──────────────┐
                                       ▼              ▼              ▼
                                   자체 SVG 렌더러   내보내기      mermaid 코드 역생성
```

이 구조 덕분에 mermaid 가 표현하지 못하는 것들이 가능해집니다.

- 노드를 원하는 자리로 끌어다 놓기
- mermaid 에 없는 도형(별·구름·사람·블록 화살표 등)
- 자유 텍스트, 손그림, 이미지
- 노드마다 다른 색·글꼴·테두리

그리고 내보내기가 깨끗해집니다. mermaid 는 라벨을 `<foreignObject>` 로 그리는데, 그게 섞인 SVG 는
이미지로 구울 때 글자가 날아갑니다. 자체 렌더러는 순수 `<text>` 만 씁니다.

## 코드와 캔버스, 무엇이 진실인가

둘 다입니다. 단 **속성별로** 나눠 가집니다.

| 무엇 | 진실의 소유자 | 저장 위치 |
|---|---|---|
| 노드·연결·라벨·도형·색 | mermaid 코드 | 코드 본문 |
| 좌표·크기·연결선 경유점 | 캔버스 | 코드 끝의 `%% dgr:layout:v1` 주석 |
| 자유 도형·텍스트·손그림 | 캔버스 | 문서 파일(JSON) |

- 코드를 고치면 → 구조가 갱신되고, **손으로 옮긴 노드의 위치는 유지**됩니다.
- 캔버스에서 노드를 옮기면 → **코드 본문은 한 글자도 바뀌지 않고** 배치 주석만 갱신됩니다.
  (사용자가 쓴 들여쓰기·주석·줄 순서를 지키기 위해서입니다)
- 캔버스에서 색·글자·도형을 바꾸면 → 코드가 다시 생성됩니다.

`%%` 로 시작하는 줄은 mermaid 가 파싱 전에 지우므로, 이 주석은 어디서 열어도 렌더에 영향을 주지 않습니다.
코드를 복사해 GitHub·Obsidian·Notion 어디에 붙여도 배치 정보가 함께 따라갑니다.

## 편집할 수 있는 것과 없는 것

| 종류 | 캔버스 자유 편집 | 비고 |
|---|:---:|---|
| `flowchart` / `graph` | ✅ | 전 기능 |
| `sequenceDiagram` | 보기·내보내기 | 코드로 편집 |
| `classDiagram` · `erDiagram` · `stateDiagram` | 보기·내보내기 | 코드로 편집 |
| `gantt` · `pie` · `mindmap` · `journey` 등 | 보기·내보내기 | 코드로 편집 |

편집 불가 종류는 mermaid 가 그린 SVG 를 그대로 보여주며, 확대·축소·내보내기는 똑같이 됩니다.
상단에 **보기 전용** 배지가 붙습니다.

## 주요 기능

**그리기**
- 도형 25종, 테마 5종, 노드별 색·테두리·글꼴·투명도·그림자
- 연결선: 직선·직각·곡선, 양쪽 화살촉 7종, 경유점 추가/이동
- 그룹(subgraph), 정렬·균등배치·크기맞춤, z 순서, 잠그기
- 스마트 가이드(스냅), 격자, 자유 그리기, 자유 텍스트

**보기**
- 트랙패드 핀치 줌 / 두 손가락 팬 / 스페이스 드래그 팬
- 화면 맞춤, 선택 영역 맞춤, 미니맵

**내보내기** (⌘E)
- PNG (1~4배), SVG, 단일 HTML(열면 바로 팬/줌), Markdown
- 다운로드 · 클립보드 복사 · 지정 폴더에 저장(Finder 에서 보기 포함)

**저장**
- 라이브러리(`~/.diagrammer/library`) — ⌘S
- Obsidian vault — ⇧⌘S. vault 는 자동 감지합니다.
  기본 설정에서 **⌘S 로 저장할 때 vault 에도 함께 기록**합니다(설정 → Obsidian 에서 끌 수 있습니다).
- 브라우저 자동 저장 — 탭을 닫았다 열어도 복구됩니다.
- 덮어쓰기 전 원본은 `~/.diagrammer/backups` 에 보관됩니다.

**Obsidian 연동**
- 노트 1개 = 다이어그램 1개. 프론트매터 + mermaid 코드블록 + (선택) SVG/PNG 첨부.
- 편집 상태(좌표·색)는 `%%` 주석 안에 gzip+base64 로 숨겨 저장 → **다시 열면 그대로 복원**됩니다.
  숨김 데이터는 Obsidian 읽기 모드에 보이지 않고, 전역 검색도 오염시키지 않습니다.
- 상단 폴더 아이콘으로 vault 의 노트를 목록에서 골라 열 수 있습니다.

## 알아두면 좋은 것

- **Obsidian 1.13 의 mermaid 신뢰 게이트**: 보관함에서 처음 mermaid 블록을 볼 때 "이 보관함에서
  Mermaid 다이어그램을 표시할까요?" 를 한 번 허용해야 그림이 보입니다. 저장이 잘못된 게 아닙니다.
- **Obsidian 과 이 앱의 mermaid 버전이 다릅니다**(11.13 vs 12). 같은 코드가 다르게 배치되는 것을 막으려고
  이 앱은 배치 엔진을 `dagre` 로 고정했습니다.
- **한글 조합 중 단축키**: 조합 중에는 낱자 단축키(V, N, T …)가 동작하지 않습니다. 다만 ⌘/Ctrl 조합은
  항상 동작하므로 한글을 입력하다가도 ⌘S 로 저장할 수 있습니다.
- **파일 서버가 꺼져 있어도** 그리기·내보내기(다운로드)는 그대로 됩니다. 저장과 Obsidian 연동만 멈춥니다.

## 로컬 서버의 안전장치

이 서버는 파일을 쓰는 권한을 가집니다. 그래서 네 겹으로 막습니다.

| 막는 것 | 방법 |
|---|---|
| 경로 탈출 (`../`) | 허용 루트 화이트리스트 + `path.resolve` 후 접두사 검증 |
| 숨김 폴더 침입 (`.obsidian/plugins`) | 경로 세그먼트가 `.` 으로 시작하면 거부 |
| 다른 로컬 페이지의 호출 | Origin 을 우리 포트로만 한정 + 모든 `/api` 에 `X-Diagrammer` 헤더 요구(프리플라이트 강제) |
| DNS rebinding | `Host` 헤더를 직접 검사 (localhost/127.0.0.1 만) |
| 설정을 통한 권한 확대 | `exportDir` 은 홈 안 일반 폴더만, `vaultPath` 는 Obsidian 이 아는 보관함만 |
| 남의 노트 덮어쓰기 | 다이아그래머가 만든 노트가 아니면 덮지 않고 새 이름으로 저장 |
| 노트에 심어진 스크립트 | 파일에서 읽은 문서는 구조를 검증하고 `nativeSvg` 는 무조건 버림 |

덮어쓰기 전 원본은 `~/.diagrammer/backups` 에 남습니다.

## 자체 점검

`npm run dev` 상태에서 <http://localhost:5273/selftest.html> 을 열면
라벨 왕복(따옴표·부등호·`#`·이모지·줄바꿈), 코드 수렴, 도형·화살표 매핑, 예약어 회피,
뷰어 전용 타입, 오류 처리, 그리고 회귀 항목(한글 id 유지·중첩 subgraph·그룹 유령 증식·linkStyle 인덱스)까지
68건을 실제 mermaid 로 돌려 통과/실패를 보여줍니다.

mermaid 를 올리거나 이스케이프 규칙을 손볼 때 이 페이지부터 확인하세요.
여기서 깨지는 항목은 대부분 **에러 없이 글자가 사라지는** 종류라, 눈으로는 뒤늦게 발견됩니다.

## 파일 구조

```
server/index.mjs          로컬 파일 서버 — 저장·읽기·vault 연동. 경로 탈출 방어가 최우선 관심사
src/core/types.ts         Scene 문서 모델(IR)
src/core/shapes.ts        도형 카탈로그 — 경로·외곽선·라벨 여백
src/core/geometry.ts      선택 판정·경계·연결선 라우팅·스냅·텍스트 측정
src/core/theme.ts         테마 5종, 색 팔레트, 스타일 프리셋
src/core/mermaid/
  engine.ts               mermaid 초기화·파싱·렌더 래퍼
  importer.ts             mermaid → Scene (구조는 파서 db, 배치는 렌더 SVG)
  emitter.ts              Scene → mermaid (이스케이프·예약어·배치 주석)
src/core/export/          SVG/PNG/HTML 내보내기
src/core/obsidian.ts      노트 조립·압축·되읽기
src/render/SceneView.tsx  화면과 파일이 공유하는 단 하나의 렌더러
src/ui/                   캔버스·상단바·도구·코드창·속성창·미니맵
src/ui/panels/            내보내기·라이브러리·Obsidian·설정·도움말·명령 팔레트
```
